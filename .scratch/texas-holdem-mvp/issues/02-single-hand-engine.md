# Complete Hand engine tracer

Status: ready-for-agent

## What to build

Build the server-authoritative Hand engine that can run one complete No-Limit Betting Hand from Blinds through settlement with standard Texas Hold'em hand evaluation.

## Acceptance criteria

- [ ] The server posts Blinds and deals private Hole Cards.
- [ ] Betting Rounds progress through preflop, flop, turn, and river.
- [ ] Fold, check, call, bet, raise, and All-In are validated server-side.
- [ ] Showdown uses standard Texas Hold'em hand ranking.
- [ ] Split Pot and Side Pot settlement are correct.
