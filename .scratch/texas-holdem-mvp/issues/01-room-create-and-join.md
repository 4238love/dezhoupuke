# Room creation and joining tracer

Status: ready-for-agent

## What to build

Build the end-to-end path where a Host creates a Private Room with table settings, receives a Room Code and Invite Link, and another human player joins by Room Code or Invite Link with a Nickname.

## Acceptance criteria

- [ ] A Host can create a Private Room with Seat count, AI count, AI Difficulty, initial Table Chips, Blinds, and Nickname.
- [ ] Room Code and Invite Link are visible and copyable.
- [ ] A player can join by Room Code and Nickname.
- [ ] A player opening an Invite Link can join after entering only a Nickname.
- [ ] Duplicate Nicknames in the same Private Room are rejected.

## Blocked by

None - can start immediately.
